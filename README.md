# 🧭 Siratech — AI Tour Guide

**Siratech** is an AI-powered tour guide designed to make exploring new destinations easier and more interactive. It helps users discover places and receive personalized recommendations based on their interests and needs.

## ✨ Features

* 🤖 **AI Tour Guide** — Get personalized travel assistance.
* 📍 **Place Discovery** — Explore destinations and attractions.
* 💬 **Interactive Experience** — Ask for guidance and receive useful travel suggestions.

## 🎯 Goal

The goal of Siratech is to create a more **personalized and convenient travel experience** by combining tourism with AI-powered recommendations.

## 🛠️ Technologies

* Artificial Intelligence
* Generative AI
* Web Development
* Interactive UI/UX

## 🚀 Project

Siratech was developed as an AI-focused project exploring how **Generative AI can enhance tourism and travel experiences**.
